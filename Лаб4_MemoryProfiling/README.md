# Лабораторная работа № 4

Тема: поиск утечек памяти и профилирование производительности в C#.

## Файлы

- `Program.cs` – вся первая часть, разделена на три части:
  - ЧАСТЬ 1 – базовый код методички (дословно);
  - ЧАСТЬ 2 – задания 1–4 (фрагменты из заданий дословно + замеры);
  - ЧАСТЬ 3 – окно программы вместо консоли;
- `CallTree.cs` – Call Tree из методички (правки по заданию помечены `ЗАДАНИЕ`)
  и профилирование собственного кода (`OwnCodeProfiler` в конце файла);
- `Lab4_Report.docx`, `Lab4_Report.pdf` – отчет.

## Запуск

Открыть `Lab4.slnx` в Visual Studio и запустить, или:

```powershell
dotnet run --project MemoryLab.csproj -c Release
```

Call Tree открывается кнопкой «Открыть Call Tree» в отдельном консольном окне.
