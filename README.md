# ССП — лабораторные работы

Лабораторные работы по дисциплине «Современные средства программирования» (C# / .NET и смежные темы).
Каждая работа лежит в отдельной папке в корне репозитория; готовые отчёты по СТП БГУИР 01-2024 собраны также в `Отчеты_СТП_БГУИР/`.

| № | Папка | Тема | Технологии |
|---|---|---|---|
| 1 | [`Лаб1_IL_JIT/`](Лаб1_IL_JIT/) | Анализ IL-кода и JIT-компиляции (IlAnalysis, JitResearch, 70+ xUnit-тестов) | C#, .NET, xUnit |
| 2 | [`Лаб2_GC/`](Лаб2_GC/) | Управление памятью, сборка мусора, LOH, boxing, утечки | C#, GC |
| 3 | [`Лаб3_Рефлексия/`](Лаб3_Рефлексия/) | Рефлексия, `System.Type`, позднее связывание, плагины (`plugins.config`) | C#, Reflection |
| 4 | [`Лаб4_MemoryProfiling/`](Лаб4_MemoryProfiling/) | Поиск утечек памяти и профилирование, Call Tree | C#, WinForms |
| 5.1 | [`Лаб5_1_Потоки/`](Лаб5_1_Потоки/) | Многопоточность: Producer-Consumer, Deadlock, Mutex | C#, Threading |
| 5.2 | [`Лаб5_2_TPL_PLINQ/`](Лаб5_2_TPL_PLINQ/) | Параллельное программирование: TPL, PLINQ, Partitioner, варианты 1–7 | C#, TPL, PLINQ |
| 6 | [`Лаб6_IoT/`](Лаб6_IoT/) | IoT: график датчика, MQTT-клиент, симулятор устройств | C#, MQTTnet, WinForms |
| 7 | [`Лаб7_СмартКонтракт/`](Лаб7_СмартКонтракт/) | Смарт-контракты (реестр студентов, книг, сотрудников) | Solidity, Remix IDE |
| 8 | [`Лаб8_Ollama/`](Лаб8_Ollama/) | Клиент Ollama и конвейер LLM-агентов | C#, Ollama API |
| 10 | [`Лаб10_Unity/`](Лаб10_Unity/) | Unity-скрипты: управление игроком, преследование врага + проверочный стенд | C#, Unity |

Дополнительно:

- [`Отчеты_СТП_БГУИР/`](Отчеты_СТП_БГУИР/) — отчёты (DOCX/PDF) по всем работам, конспект «Процессы, потоки, прерывания».
- [`Дополнительно/`](Дополнительно/) — альтернативные версии ЛР2, ЛР3 и ЛР5.2 (`lab-6-parallel`) с шпаргалками и скриптами сборки отчётов.

## Запуск

Для .NET-проектов (нужен .NET SDK):

```
dotnet run -c Release --project <папка_проекта>
```

Подробности — в README/SETUP внутри папок работ (например, [`Лаб1_IL_JIT/SETUP.md`](Лаб1_IL_JIT/SETUP.md)).
Артефакты сборки (`bin/`, `obj/`, `.vs/`), архивы и временные файлы в репозиторий не входят (см. `.gitignore`).
