# ССП — лабораторные работы

Репозиторий с лабораторными работами по дисциплине C# / платформа .NET.
Каждая лабораторная работа находится в отдельной папке в корне репозитория.

## Структура

- [`Лаб1_IL_JIT/`](Лаб1_IL_JIT/) — Лабораторная работа №1. "Платформа .NET:
  анализ IL-кода и JIT-компиляции".
  - `IlAnalysis/` — Задания 1–3 (анализ IL-кода, ILGenerator, DynamicMethod)
  - `JitResearch/` — Задания 4–5 (влияние JIT-компиляции на производительность)
  - `Tests/` — модульные тесты (xUnit, 70+ тестов) на код обоих проектов выше
  - `SETUP.md` — подробная инструкция по установке окружения
  - `THEORY.md` — теория по IL / JIT / CLR
  - `Отчет_Лаб1.docx` — электронный отчёт по лабораторной работе

## Быстрый старт

См. [`Лаб1_IL_JIT/SETUP.md`](Лаб1_IL_JIT/SETUP.md) для пошаговой установки
.NET SDK и всего необходимого окружения.
